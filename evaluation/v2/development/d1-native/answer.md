The practical route is NASA’s historical space photography, but this pack is **provisional, not ready for production**: I inspected three individual NASA records and their reuse policy, but could not extract and verify all three direct image URLs without fetching image binaries. Empty CSV URL fields mean unresolved, not permission or availability.

Use Earthrise (1968), The Blue Marble (1972), and Pale Blue Dot Revisited (1990 observation, 2020 processing) for an exhibit about Earth’s place in space. Earthrise’s record offers a “Highest-Resolution” JPEG (1.80 MB). Pale Blue Dot offers a 29.85 MB TIFF for the 2020 version; do not label that processing as the untouched 1990 original. [Earthrise](https://science.nasa.gov/resource/apollo-8s-iconic-earthrise/), [Blue Marble](https://science.nasa.gov/resource/the-blue-marble/), [Pale Blue Dot](https://science.nasa.gov/resource/voyager-pale-blue-dot-download/).

NASA’s published policy expressly permits educational and informational uses including public exhibits and web pages, asks for source acknowledgment, and excludes third-party copyright material. The inspected records credit NASA or NASA/JPL-Caltech and display no separate copyright warning in the retrieved text. This supports this museum use conditionally; it is not a claim that everything on NASA’s site is unrestricted. [NASA media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).

The starting institutions exposed important traps. Smithsonian’s indexed individual Moon record nmah_1184258 labels metadata CC0 while the image says “Usage Conditions Apply.” I excluded it. Its direct record failed to open, so this finding is search-retrieved, not a successful live record inspection. Smithsonian’s indexed FAQ says assets must themselves carry CC0 and its API requires registration; metadata licensing cannot authorize an image. [Moon record](https://www.si.edu/object/photograph-moon%3Anmah_1184258), [Open Access FAQ](https://www.si.edu/openaccess/faq).

LOC’s indexed Cassiopeia and Ursa Major records offer approximately 50 MB TIFFs and report no known U.S. publication restrictions, with a foreign-law caveat. Direct opens returned 403, so I did not bypass them or promote their indexed details to fully verified selections. LOC explicitly warns that online availability does not establish reuse rights. An API or site’s access rules are separate from the rights attached to each object. [Cassiopeia](https://www.loc.gov/pictures/item/2002695396/), [Ursa Major](https://www.loc.gov/pictures/item/2002695502/), [LOC copyright guidance](https://www.loc.gov/legal/security-copyright-and-privacy/understanding-copyright/).

**Invalidation check:** before production, confirm the precise linked rendition still has the same NASA credit and no third-party notice, then verify pixel dimensions against the intended print size. A restrictive asset notice or insufficient native resolution invalidates that selection. File size alone does not prove resolution. Direct-file availability and print quality remain unverified here. Public metadata retrieval through NASA’s API was unavailable in the web tool, and local HTML retrieval failed DNS resolution. No image binaries were downloaded.
