# Offline notes backup and recovery

A student group edits plain Markdown notes on Android phones and macOS laptops. Their starting idea is Obsidian Git or Syncthing, with no paid synchronization, no always-on server and no new accounts. They need offline editing and a credible way to recover accidentally deleted or conflicting notes. Investigate current primary documentation and project status, identify the most feasible route and a materially different alternative, and specify a minimal restore/conflict rehearsal. Separate synchronization, version history and independent backup. Do not install apps, pair devices, access user files/accounts or write remotely. Make material platform and maintenance constraints explicit. Max 650 words.
