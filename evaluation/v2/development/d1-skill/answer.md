The object advisories report no known publication restrictions in the United States, while expressly qualifying use elsewhere. This is a source assessment, not a CC0 license or an unconditional permission grant. A globally downloadable sheet therefore needs a destination-sensitive rights check. LOC’s general availability and copying guidance do not replace each object’s rights statement. [LOC rights guidance](https://guides.loc.gov/p-and-p-rights-and-restrictions/).

The Smithsonian starting point revealed a useful trap: its **Photograph of the Moon**, record nmah_1184258, labels metadata CC0 while the image carries usage conditions. Free educational use does not automatically establish unrestricted redistribution. The Smithsonian distinguishes these categories in its [terms](https://www.si.edu/termsofuse) and [Open Access FAQ](https://www.si.edu/openaccess/faq). I would not use that image as an unrestricted reusable asset on the evidence retrieved. [Individual Moon record](https://www.si.edu/object/photograph-moon%3Anmah_1184258).

**Check that could invalidate this route:** before production, confirm each current individual record still carries the reported advisory and that all three TIFF links return the matching full-resolution image. Confirm pixel dimensions against the intended panel size and inspect any restrictions relevant to worldwide redistribution. A changed advisory, unavailable master, mismatched image or inadequate resolution defeats this recommendation.
